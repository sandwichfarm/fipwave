## Trust Boundaries

| Boundary | Description |
|---|---|
| Local browser → loopback proof action | Untrusted method, origin, and request state could trigger privileged Docker execution. |
| Private shared Unix socket → Node control client | Local filesystem authorization does not authenticate response contents; frames can be malformed, stale, oversized, partial, or unavailable. |
| A fips0 challenge → B fips0 responder | The in-band response can be stale, replayed, malformed, or from the wrong source/session. |
| Current/previous epoch → displayed proof | Stale outcomes and counters must not retain current authority. |

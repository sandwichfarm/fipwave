## Trust Boundaries

| Boundary | Description |
|---|---|
| Host/LAN → published Compose ports | A wide bind could become an alternate packet path or local attack surface. |
| FIPS container → kernel/TUN | Network administration privileges must remain exactly scoped. |
| Smoke process → Docker daemon/projects | Cleanup must not affect unrelated containers or projects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-20 | Spoofing / Elevation | host publications | high | mitigate | Only explicit 127.0.0.1 browser publication; no FIPS packet port, host network or LAN bind. |
| T-02-21 | Elevation of Privilege | FIPS service | high | mitigate | Exact NET_ADMIN plus `/dev/net/tun`, no privileged/SYS_ADMIN/extra capability, source/rendered/inspect gates. |
| T-02-22 | Tampering | generated role config | high | mitigate | Generate from the typed authority into owned temporary files; no committed duplicate secrets. |
| T-02-23 | Denial of Service | Compose smoke ownership | medium | mitigate | Unique project name, bounded waits, argument arrays and guaranteed owned down/temporary cleanup. |
| T-02-24 | Repudiation | topology evidence | medium | mitigate | Persist/render exact source/config/inspect facts as Loopback only; never promote to Open air. |
| T-02-SC | Tampering | container build inputs | high | mitigate | Pinned Node/Rust bases, npm/cargo locks, vendored FIPS provenance and no mutable build-time clone. |

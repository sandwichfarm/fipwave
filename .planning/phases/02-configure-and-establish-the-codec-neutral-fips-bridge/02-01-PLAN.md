## Phase Goal

**As an** operator, **I want to** resolve either laptop from one authority and connect FIPS to its local browser through a codec-neutral binary bridge, **so that** complete opaque packets can enter the normal FIPS transport lifecycle without inventing an acoustic-peer claim.

<objective>
Prove the phase architecture with one production-quality, end-to-end complete-packet path before expanding the Rust transport, recovery, deployment and UI surfaces.

Purpose: Retire the highest-risk boundary first: one honest 1357-byte opaque packet must survive role resolution, fixed binary framing, endpoint-role checks and bounded relay in each local direction.
Output: The Wave 0 configuration and packet-bridge tests plus the durable TypeScript contracts they exercise.
</objective>

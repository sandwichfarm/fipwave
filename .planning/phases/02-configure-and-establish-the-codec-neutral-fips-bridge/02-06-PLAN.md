</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Bridge/FIPS messages → browser state/DOM | Untrusted state/error text can cause false readiness, disclosure or script/markup injection. |
| Armed browser runtime → codec-neutral adapter | Untrusted, stale or unarmed packets could enter the modem boundary or be reflected to FIPS. |
| Old browser callbacks → recovered UI | Stale async work can overwrite the current epoch after reset. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-25 | Tampering | bridge state reducer | high | mitigate | Exact schema/type/range/transition validation and fail-closed partial/unknown state. |
| T-02-26 | Information Disclosure | DOM/accessibility/error rendering | high | mitigate | Safe scalar allowlist, 240-character single-line errors, textContent and tests for nsecs/raw frames/stacks. |
| T-02-27 | Spoofing | readiness/MTU presentation | high | mitigate | Readiness requires validated local fields; MTU below 1357 fails and local state never implies peer/acoustic/ping readiness. |
| T-02-28 | Replay | reset callbacks/snapshots | high | mitigate | Capture generation/epoch for every async completion and commit recovered state only after new-epoch acknowledgement. |
| T-02-29 | Denial of Service | long text / telemetry | medium | mitigate | Bound error text, render scalar snapshot only, no event feed, wrap/scroll browser backstops. |
| T-02-30 | Tampering / Replay | FIPS packet adapter boundary | high | mitigate | Exact binary frame, size, epoch, generation and armed-readiness gates plus byte-identity browser coverage and reset invalidation. |
| T-02-SC | Tampering | UI dependency surface | high | mitigate | No new package/registry block; existing npm audit/lock gate and vanilla DOM stack remain. |
</threat_model>

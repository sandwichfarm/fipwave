## Phase Goal

**As an** operator, **I want to** resolve either laptop from one authority and connect FIPS to its local browser through a codec-neutral binary bridge, **so that** complete opaque packets can enter the normal FIPS transport lifecycle without inventing an acoustic-peer claim.

<objective>
Expand the packet tracer into a bounded, observable and epoch-safe local bridge with one recovery operation.

Purpose: Temporary browser/FIPS outages and malformed or stale input must become explicit recoverable state rather than memory growth, duplicate delivery or false readiness.
Output: Per-direction resource bounds, safe snapshots/counters/errors and full reset/reconnect backend behavior under real local WebSocket integration tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser/FIPS frames → queue/counter state | Malformed or high-volume input can corrupt state or exhaust memory. |
| Old epoch/generation → recovered session | Replay or delayed completion can inject stale packets or false readiness. |
| Internal errors/config → safe snapshot | Operational visibility must not disclose secrets or raw protocol data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-15 | Denial of Service | bidirectional packet queues | high | mitigate | Independent item/byte/age caps, reject-before-mutation and no automatic retry. |
| T-02-16 | Tampering | endpoint role/type/size validation | high | mitigate | Decode and exact-role/type/length validation before queue/counter changes. |
| T-02-17 | Spoofing / Replay | reset epoch and async generations | high | mitigate | One epoch authority, urgent watermark reservation and generation checks on all completions. |
| T-02-18 | Information Disclosure | safe state/errors | high | mitigate | Scalar allowlist, 240-character single-line safe messages and tests for nsecs/raw frames/query strings. |
| T-02-19 | Repudiation | accepted counters/timestamps | medium | mitigate | Count only successful current-epoch deliveries and preserve explicit rejection/last-error state. |
| T-02-SC | Tampering | dependency execution | high | mitigate | Existing npm audit/lock gate runs first; no package is added. |
</threat_model>

</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Role/override input → immutable runtime config | Untrusted launch/config values choose identity, peer and ports. |
| Private config → runner/browser/log projection | Disposable secrets must not leak through ordinary observability. |
| Runner → local resource lifecycle | Cleanup must not terminate unrelated processes/services. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-10 | Spoofing | role/peer resolver | high | mitigate | Exact a/b union, complementary peer checks and immutable result. |
| T-02-11 | Tampering | optional overrides | high | mitigate | Exact schema, semantic port/MTU/timing checks and fail-closed unknown keys. |
| T-02-12 | Information Disclosure | public runner config/logs/errors | high | mitigate | Deliberate allowlisted projection and tests scanning all serializations for both nsecs. |
| T-02-13 | Denial of Service | resource cleanup | medium | mitigate | Reverse-order bounded idempotent close and safe aggregation of cleanup failures. |
| T-02-14 | Elevation of Privilege | process ownership | high | mitigate | Close only registered returned handles; no name/port/global-process termination. |
| T-02-SC | Tampering | dependency execution | high | mitigate | Existing npm lock/audit gate runs before tests; no direct package is added. |
</threat_model>

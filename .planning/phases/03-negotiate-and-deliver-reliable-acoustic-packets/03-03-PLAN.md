## Phase Goal

**As a** demo operator, **I want to** establish a measured and mutually
committed acoustic session between both laptops, **so that** complete FIPS
packets receive safe bounded deterministic half-duplex delivery below the FIPS
boundary.

<objective>
Define the exact versioned acoustic modem profile/settings model and the strict FAS1 binary units that every later session path uses.

Purpose: Establish one validated identity and geometry for bootstrap, calibration, data, ACK, heartbeat, and recovery without conflating a pinned fallback profile with the generalized model.
Output: Pure FAS1 codec/CRC/settings functions, hostile tests, and centralized validated acoustic bounds.
</objective>

<assumption_delta_decision>
Primary noun: exact versioned acoustic modem profile/settings model.
Decision: promote — the generalized profile/settings model is the session identity; pinned `quiet-audible-7k-v1` / `audible-7k-channel-0` is one conservative bootstrap/fallback variant, not a second required identity beside it.
Invariant test: every selected A→B or B→A profile is advertised by both roles and resolves to the same real encoder/decoder implementation used by transmit and receive.
</assumption_delta_decision>

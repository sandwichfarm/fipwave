batch PHY without endangering the working Quiet fallback, **so that** a fast
primary path is used only when it proves itself quickly.

make every failure route immediately to the already runnable Quiet path.

new streaming, platform, or DSP work.

Output: A portable native batch executable, bounded PCM worker, ordered
early-abandon gate, and exact runbook commands.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cached C source → native executable | Upstream source is compiled and executed locally. |
| bridge → native child | Untrusted captured PCM and case metadata enter a subprocess. |
| native result → qualification state | Malformed, replayed, or duplicate output could be counted as a physical case. |

| T-01-25 | Injection / DoS | native child process | high | mitigate | Fixed executable, allowlisted subcommands, no shell, capped stdin/stdout/stderr, one child, timeout, and kill on reset. |

## Phase Goal

**As a** demo operator, **I want to** qualify the exact two laptops' audible
browser-audio codec path and Docker/TUN substrate, **so that** FIPS integration
begins only with evidence-backed codec and host assumptions.

<objective>
Implement the deterministic FWAV protocol, canonical report contract, and
committed qualification corpus consumed by every codec and UI path.

Purpose: Physical evidence must enter one strict, codec-neutral, replayable
contract before any selection decision is possible.

Output: FWAV encoder/decoder, report validator/persistence, deterministic
corpus generator/manifest, and focused tests.
</objective>

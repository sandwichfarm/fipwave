<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command line / filesystem → browser config | Host identity and physical-evidence authority enter the runner. |
| internet → codec cache | Executable JavaScript and C source enter from pinned upstreams. |
| cache → browser | Executable files and licenses cross an HTTP serving boundary. |
| browser → bridge | Untrusted frames could try to spoof runner-owned evidence fields. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-20 | Spoofing / Tampering | qualification config | high | mitigate | Validated runner arguments, immutable endpoint, server stamping, browser-field rejection, and explicit physical flag requiring passed exact-host TUN evidence. |
| T-01-21 | Tampering | codec fetch/cache | high | mitigate | Exact HTTPS URL/name/hash/size/license lock, temporary download, offline check, and atomic replacement. |
| T-01-22 | Traversal / Information disclosure | asset and UI server | high | mitigate | Exact route/filename allowlists, canonical containment, symlink rejection, fixed MIME, and no directory serving. |
| T-01-23 | Elevation of privilege | bridge origin | high | mitigate | Constant loopback bind, exact same-origin upgrade, no remote host option, and binary frame validation. |
| T-01-SC | Tampering | npm installs | high | mitigate | No dependency is added; the existing audited lockfile remains mandatory. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runner config → browser | Trusted identity/evidence authority becomes read-only UI/runtime state. |
| sound → Quiet receiver | Corrupt, duplicated, partial, or stale fragments enter evidence. |
| browser result → runner report | Untrusted measurements could spoof authoritative fields. |
| reports → selection | Two independent runs and TUN evidence are combined into a trust decision. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-24 | Spoofing | browser report fields | high | mitigate | Runner stamping, conflict rejection, immutable config, literal roles, and exact host matching. |
| T-01-25 | Tampering / Replay | Quiet fragments | high | mitigate | Versioned envelope, epoch/sender/case/fragment identity, declared length, SHA-256, dedupe, and complete-only reassembly. |
| T-01-26 | Elevation / Spoofing | TUN evidence | high | mitigate | Require `source: exact_host`, passed status, every authority/lifecycle check passed, and canonical validation. |
| T-01-27 | Alternate path | corpus scheduling | high | mitigate | Local `onFinish` plus fixed guard only; no acknowledgements, remote result waits, retries, ARQ, or page-to-page networking. |
</threat_model>

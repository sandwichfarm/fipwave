**As a** demo operator, **I want to** qualify the exact two laptops' audible
browser-audio codec path and Docker/TUN substrate, **so that** FIPS integration
begins only with evidence-backed codec and host assumptions.

fixture path, and exact-evidence verifier before any hardware checkpoint.

or unqualified—without a manual pass control or codec-specific leakage.

Output: Adapter seam, gate reducer, CLI, server wiring, complete qualification
console, and automated fixture/browser tests.
</objective>

# Quick Task 260729-3jw: Sub-five-second FIPS acoustic bootstrap

## Goal

Make the normal demo path establish both FIPS peers from Start / Connect in under five seconds.

## Tasks

1. Measure the current physical startup path and identify whether guard time or waveform airtime dominates.
2. Expose the native Cyrinx encoder/decoder as a packet worker for arbitrary opaque FIPS frames, then route browser PCM and FIPS packet admission through that worker.
3. Add unit and self-loop timing assertions, then run the real speaker-to-microphone proof that both actual FIPS peers connect in under five seconds.

## Must haves

- The measured Quiet two-frame bootstrap is recorded as 35.328 seconds, proving guard-only tuning cannot satisfy the goal.
- Cyrinx can carry opaque FIPS frames up to its 1,536-byte application MTU and uses a 2.005-second receive window.
- A successful default Start / Connect reaches both actual FIPS peer-connected states in less than five seconds.
